# Daamky Client — восстановленный исходный проект

Восстановленный исходный код клиента Daamky, полученный из исходного
JAR-файла и адаптированный в отдельный собираемый проект на Fabric.

## Используемое окружение

- Minecraft: `1.21.4`
- Fabric Loader: `0.16.14`
- Java: `21`
- Система имён: Fabric Intermediary
- Маппинги: Yarn `1.21.4+build.8`
- Fabric API: `0.119.4+1.21.4`
- Gradle: `8.12.1`
- Fabric Loom: `1.10.5`

Перед декомпиляцией символы Minecraft были преобразованы в именованные
символы Yarn.

Из-за особенностей обфускации некоторые имена классов и членов,
которые невозможно было достоверно восстановить, получили временные
имена. Имена не выдумывались без подтверждения из исходного байткода.

Основная структура проекта была адаптирована под Daamky.

## Зависимости

Проект использует:

- Fabric API
- Lombok
- JSR-305
- Validation API
- ZXing
- HttpRequest
- Thumbnailator
- NanoHTTPD
- Netty
- Reactor Netty
- OkHttp
- JavaFX

Встроенные зависимости находятся в:

`src/main/resources/META-INF/jars/`

Для сборки проекта не требуется внешняя папка `libraries` лаунчера.
